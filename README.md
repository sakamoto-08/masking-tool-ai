# masking-tool-ai

学習用マスキングツールの品質改良版です。機能は元アプリと同じで、実装の安全性と見通しを上げています。

入力したテキストは外部へ送信せず、保存もしません。処理はブラウザ内だけで完結します。

## 使い方

1. `index.html` をブラウザで開く
2. 入力欄に文章を入れる
3. 「電話番号を検出してハイライト」を押す
4. ハイライトをクリックすると、その番号をマスク対象から外せる（もう一度クリックすると戻る）
5. 「結果をコピー（ONは [MASK]）」を押す

コピー結果の仕様:

- ON の番号 → ` [MASK] `（前後にスペースあり）
- OFF の番号 → 元の電話番号のまま

## 検出対象

対象になるのは、次の形式だけです。

- 例: `03-1234-5678` / `090-1234-5678`
- 正規表現: `\d{2,4}-\d{2,4}-\d{4}`

対象外（仕様どおり検出しません）:

- ハイフンなし（`09012345678`）
- 国際表記（`+81-90-...`）

マスク処理はコピー時に走ります。検出ボタンはハイライト表示までです。

## ファイル構成

```text
index.html
css/style.css
js/phone.js      # 検出とトークン分割
js/render.js     # 安全なハイライト描画
js/copy.js       # コピー用テキストの組み立て
js/main.js       # 画面操作
tests/run.html   # ブラウザで開くテスト
tests/phone.test.js
```

## テスト

`tests/run.html` をブラウザで開きます。検出・非検出・ON/OFF のコピー結果・HTML を実行しないことの確認が走ります。

スマホ幅（375px 程度）の見た目は、ブラウザの開発者ツールで確認してください。

## 元アプリとの違い

機能は変えていません。主に次の品質を上げています。

- ユーザー入力を `innerHTML` に入れない
- 検出・描画・コピーをファイル分割する
- コピー失敗時のメッセージを出す
- README と動作確認テストを追加する
