# masking-tool-ai

自力で実装した [masking-tool](https://github.com/sakamoto-08/masking-tool) を題材に、Cursor へ要件を渡して品質を上げた練習用プロジェクトです。機能は元アプリと同じで、増やしていません。

## デモ

https://sakamoto-08.github.io/masking-tool-ai/

## このリポジトリについて

このリポジトリは、電話番号マスキングツール [masking-tool](https://github.com/sakamoto-08/masking-tool) の品質向上版です。元アプリは自分で実装し、こちらでは AI エージェント（Cursor）に指示を出しながら、同じ機能を安全で見通しのよい形に組み直しました。

目的は次の2点です。

1. AI エージェントへの要件定義・指示出しの練習
2. 生成されたコードをレビューし、受け入れ条件で検証するプロセスの実践

機能を増やすと差分が分かりにくくなるため、意図的に機能追加はしていません。比較対象は実装の品質（安全性、構造、エラー処理、ドキュメントとテスト）です。

## 機能

masking-tool と同じ機能です。

- 入力したテキストから電話番号を検出し、ハイライト表示する
- ハイライトをクリックすると、その番号をマスク対象から外せる（もう一度クリックすると戻す）
- 結果をクリップボードへコピーする
  - ON の番号 → ` [MASK] `（前後にスペースあり）
  - OFF の番号 → 元の電話番号のまま
- 入力・出力したテキストは外部へ送信せず、保存もしない（処理はブラウザ内で完結する）

検出対象は次の形式だけです。

- 例: `03-1234-5678` / `090-1234-5678`
- 正規表現: `\d{2,4}-\d{2,4}-\d{4}`

対象外（仕様どおり検出しません）:

- ハイフンなし（`09012345678`）
- 国際表記（`+81-90-...`）

マスク処理はコピー時に走ります。検出ボタンはハイライト表示までです。

## masking-tool との違い

機能は変えていません。実装の品質を上げています。

### XSS対策

元アプリは検出結果を文字列置換し、`innerHTML` で出力欄へ入れていました。入力に `<script>` などが含まれると、HTML として解釈される余地があります。

こちらではユーザー入力を `innerHTML` に入れません。電話番号は `createElement` で `span` を作り、それ以外は `createTextNode` で描画します。

### ファイル分割

元アプリは検出・描画・コピー・画面操作が `js/main.js` にまとまっていました。こちらは次のように分けています。

```text
js/phone.js   # 検出とトークン分割
js/render.js  # 安全なハイライト描画
js/copy.js    # コピー用テキストの組み立て
js/main.js    # 画面操作
```

### エラーハンドリング

元アプリはコピー成功時に `alert` を出し、失敗時の案内はありませんでした。こちらは画面上のステータス表示に切り替え、クリップボードが使えない場合とコピー失敗時にもメッセージを出します。

### README・テストの整備

元アプリの README はタイトルのみでした。こちらでは使い方・検出仕様・品質差分を README に書き、ブラウザで開く動作確認テスト（`tests/run.html`）を追加しています。

## 開発の進め方

Cursor にコードを任せる前に、守ること・変えてよいこと・やってはいけないことを要件として渡しました。生成後は、自分でレビューし、次の受け入れ条件で動作確認しています。

### Cursor に渡した要件

**守ること**

- 機能は masking-tool と同一にする（検出対象、ON/OFF、コピー結果の置換ルールを変えない）
- ON の番号は ` [MASK] `（前後スペースあり）、OFF は元の番号のまま残す
- 処理はブラウザ内で完結させる（入力の外部送信・保存をしない）
- HTML / CSS / JavaScript のみで動かす（ビルドツールやフレームワークを入れない）

**変えてよいこと**

- `innerHTML` をやめ、DOM API で安全に描画する
- 検出 / 描画 / コピー / 画面操作をファイル分割する
- `alert` をやめ、コピー失敗などを画面上で伝える
- README と動作確認テストを追加する
- 機能を変えない範囲でのマークアップ・スタイルの整理

**禁止事項**

- 機能追加（新しい検出対象、新しい画面操作など）
- ユーザー入力を `innerHTML` で描画すること
- npm などのビルド手順を前提にすること

### 受け入れ条件と動作確認

生成後、次を満たすことを確認しました。

- 電話番号（`03-1234-5678` / `090-1234-5678`）が検出され、ハイライトされる
- ハイライトの ON/OFF 切り替え後、コピー結果が仕様どおりになる（ON は ` [MASK] `、OFF は元番号）
- 入力に `<script>` タグを含めても実行されず、文字として表示される
- スマホ幅（375px）でレイアウトが崩れない

検出・コピー結果・XSS 対策は `tests/run.html` でも確認できます。375px の見た目は、ブラウザの開発者ツールで確認しました。

## 使用技術

## ローカルでの動かし方

1. このリポジトリをクローンする
2. `index.html` をブラウザで開く
3. 入力欄に文章を入れ、「電話番号を検出してハイライト」を押す
4. ハイライトをクリックすると、その番号をマスク対象から外せる
5. 「結果をコピー（ONは [MASK]）」を押す

動作確認テストは `tests/run.html` をブラウザで開きます。検出・非検出・ON/OFF のコピー結果・HTML を実行しないことの確認が走ります。
