# masking-tool-ai

テキスト中の電話番号・メール・住所・企業名・氏名を検出し、コピー時に種別ラベルへ置き換えるブラウザ用マスキングツールです。

自力で実装した [masking-tool](https://github.com/sakamoto-08/masking-tool) を題材に、AI エージェント（Cursor）へ要件を出して品質を上げ、検出対象を広げた練習用プロジェクトです。

## デモ

https://sakamoto-08.github.io/masking-tool-ai/

## このリポジトリについて

元になった [masking-tool](https://github.com/sakamoto-08/masking-tool) は、電話番号をハイライトしてコピー時にマスクするツールを自分で実装したものです。こちらでは Cursor に指示を出し、生成物をレビュー・検証しながら作り直しています。

目的は次の2点です。

1. AI エージェントへの要件定義・指示出しの練習
2. 生成されたコードをレビューし、受け入れ条件で検証するプロセスの実践

最初は機能を変えず、安全性と見通しを上げるところから始めました。その後、同じ進め方で検出対象（ハイフンなし電話、メール、住所、企業名、氏名）とコピー時の種別ラベルを追加しています。

入力・出力したテキストは外部へ送信せず、保存もしません。処理はブラウザ内で完結します。

## 機能

### 検出対象

| 種別 | 例 | 検出しない例 |
| --- | --- | --- |
| 電話番号 | `03-1234-5678` / `090-1234-5678` / `09012345678` | 国際表記（`+81-...`）、前後が数字の長い列 |
| メール | `test@example.com` / `user.name+tag@example.co.jp` | `@` がない、domain / TLD が欠けているもの |
| 住所 | `東京都渋谷区道玄坂1-2-3` / `大阪府大阪市北区梅田1丁目2番3号` | 都道府県だけ、市区町村だけ、番地だけ |
| 企業名 | `株式会社サンプル商事` / `（株）テスト工業` | `株式会社` だけ、`サンプル` / `商事` だけ |
| 氏名 | `山田太郎` / `佐藤花子` / `鈴木一郎` | 姓だけ、名だけ、`東京` / `会社` など |

氏名はよくある姓＋名の組み合わせに限定しています。辞書にない姓名は検出しません。

検出ボタンはハイライト表示までです。マスク処理はコピー時に走ります。

### マスキング表記

ハイライトが ON の対象は、コピー時に次のラベルへ置き換えます（前後にスペースあり）。OFF なら元の文字列のままです。

| 種別 | ON のコピー結果 |
| --- | --- |
| 氏名 | ` [氏名] ` |
| メール | ` [メール] ` |
| 電話番号 | ` [電話番号] ` |
| 住所 | ` [住所] ` |
| 企業名 | ` [企業名] ` |

例:

`山田太郎と test@example.com と 03-1234-5678 と 東京都渋谷区道玄坂1-2-3 と 株式会社サンプル商事`

→ ` [氏名] と  [メール]  と  [電話番号]  と  [住所]  と  [企業名] `

### ハイライトの ON / OFF

検出後、ハイライトをクリックするとマスク対象から外せます。もう一度クリックすると戻します。

## 使い方

1. [デモ](https://sakamoto-08.github.io/masking-tool-ai/) を開くか、このリポジトリの `index.html` をブラウザで開く
2. 入力欄に文章を入れる
3. 「電話・メール・住所・企業・氏名を検出してハイライト」を押す
4. マスクしたくない箇所はハイライトをクリックして OFF にする
5. 「結果をコピー（ONは種別ラベル）」を押す

## 技術的なポイント

HTML / CSS / JavaScript のみです。ビルドツール、バンドラ、フレームワークは使っていません。

品質面では次を重視しています。

- **XSS 対策**: ユーザー入力を `innerHTML` に入れない。`createElement` / `createTextNode` で描画する
- **ファイル分割**: 検出・描画・コピー・画面操作を分けている
- **エラーハンドリング**: コピー成功・失敗を `alert` ではなく画面上のステータスで伝える
- **テスト**: `tests/run.html` をブラウザで開いて、検出・非検出・コピー・XSS を確認できる

```text
js/phone.js    # 電話番号の検出とトークン分割
js/email.js    # メールアドレスの検出
js/address.js  # 日本の住所の検出
js/company.js  # 企業名・組織名の検出
js/person.js   # 個人名（姓名）の検出
js/render.js   # 安全なハイライト描画
js/copy.js     # コピー用テキストの組み立て
js/main.js     # 画面操作
```

元アプリ（masking-tool）は検出・描画・コピーが 1 ファイルにまとまり、`innerHTML` と `alert` を使っていました。

## 開発の進め方

Cursor にコードを任せる前に、守ること・変えてよいこと・やってはいけないことを要件として渡します。生成後は自分でレビューし、受け入れ条件で動作確認します。

守っていること（現在）:

- 処理はブラウザ内で完結させる（入力の外部送信・保存をしない）
- HTML / CSS / JavaScript のみで動かす
- ユーザー入力を `innerHTML` で描画しない
- 既存の検出・ON/OFF・コピーの流れを壊さない

受け入れ確認の観点:

- 電話・メール・住所・企業名・氏名が検出され、ハイライトされる
- ON は種別ラベル、OFF は元の文字列になる
- 入力に `<script>` を含めても実行されず、文字として表示される
- スマホ幅（375px）でレイアウトが崩れない

375px の見た目は、ブラウザの開発者ツールで確認しています。

## テストの実行方法

`tests/run.html` をブラウザで開きます。検出・非検出・トークン分割・ON/OFF のコピー結果・HTML を実行しないことの確認が走ります。
